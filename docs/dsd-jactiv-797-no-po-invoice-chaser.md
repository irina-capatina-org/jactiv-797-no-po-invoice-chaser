## 1. Solution Overview

The No-PO Invoice Chaser automation queries Coupa on a weekday schedule (10:00 Romania time) for draft and new invoices from the past seven days, excludes credit notes, counts those without a properly linked purchase order, and sends a Slack Block Kit message to the AP SME (member WLX9BD8FN) if count > 0. On clean days (count = 0), nothing is sent. The automation is configured for cloud delivery with no external inputs or consumer-facing outputs other than the Slack notification.

**Delivered components:**

| Project | Type | Role | Entry point | Notes |
|---|---|---|---|---|
| `no-po-invoice-chaser-api` | API Workflow | Primary | `Workflow.json` | Single-project solution; no dispatcher/performer split |

## 2. As-Built Architecture

Workflow `code/no-po-invoice-chaser-797/no-po-invoice-chaser-api/Workflow.json` (19 activities): compute 7-day window → query Coupa (draft/new, date bounds, limit 50) → filter (exclude credit notes, linked-PO invoices) → if count > 0: compose Slack Block Kit message and POST to channel WLX9BD8FN, validate response, mark sent → log result → return `{status, qualifying_count, slack_sent}`. Both connections are existing Integration Service integrations (not created by build).

**Deviations from SDD:** None.

## 4. Exception and Error Handling

| Error ID | Trigger | Detection | Handling | Outcome |
|---|---|---|---|---|
| S1 | Coupa auth fails | HTTP 403 or token exception | Exception throws; logged to Orchestrator | Run marked failed; no Slack sent |
| S2 | Coupa query fails | HTTP non-200 or parse exception | Exception throws; logged to Orchestrator | Run marked failed; no Slack sent |
| S3 | Slack delivery fails | Slack `ok !== true` or HTTP error | `Javascript_ValidateSlack` (line 370) throws | Run marked failed |
| S4 | Timeout/network unreachable | Connection timeout | Exception throws | Run marked failed; no Slack sent |
| S5, S6 | Any other activity exception | Script or connector throws | Exception bubbles up | Run marked failed |
| B1 | Credit note | `invoice-type === "Credit Note"` | Excluded in `Javascript_FilterAndCount` (line 212) | Logged but not counted |
| B2 | PO not linked | Both `po-number` and `order-header-num` empty | Excluded in `Javascript_FilterAndCount` | Logged but not counted |

No retry logic is configured. Failed runs are reported to Orchestrator logs only.

## 5. Operations Runbook

**Trigger & schedule:** Orchestrator schedule, weekdays 10:00 Romania time (EET/EEST). Must be created at deploy time in folder `no-po-invoice-chaser-797`; not part of build.

**Manual invocation:** `uip job start` with no input parameters. Expected runtime 10–20 seconds.

**Logs & output:** Console logs at line 429 show `qualifying_count=N` and `slack_sent=true|false`. API returns `{ status: 'Successful', qualifying_count: N, slack_sent: boolean }`.
